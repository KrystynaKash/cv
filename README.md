# Моє портфоліо
## Опис
Це веб-додаток, створений за допомогою React, що демонструє мої плани на майбутнє, цікаві факти про моє місто та погоду. Ви можете переглядати різні сторінки, дізнаватись інформацію та брати участь у опитуваннях.
## Технології
- React
- React Router
- WeatherAPI
- CSS (для стилізації)
- Бібліотеки для іконок: react-icons
